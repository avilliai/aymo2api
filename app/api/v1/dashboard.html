连接设置

同源部署时地址留空即可。保存后会立即重新读取账号列表。

导入账号

每行支持 email|password|session_token，也支持直接粘贴 JSON 数组。含 cookies、org_id、user_id 等字段时请使用 JSON。
session_token 为 __Secure-better-auth.session_token 的值；只填 email|password 时会在探测阶段自动登录（需要 Turnstile solver）。

启动注册任务

邮箱 worker 与 Turnstile solver 配置来自服务端环境变量。注册走 better-auth 邮箱验证流程，任务在后台运行；请先用小数量确认邮箱与 solver 配置正常。
